### DOMAIN 01: VOICE AGENT ENGINEERING
**Mission:** Make the AI voice agent at (615) 784-5747 indistinguishable from a human receptionist.

**Known Issues:** Random pauses mid-conversation, changes topic unprompted, says random/irrelevant things. Greeting was too long — shortened to "Thanks for calling Demo HVAC Services, how can I help you today?" — needs retesting.

**Core Capabilities:**
- Write optimized voice agent prompts (short/medium/long versions, all under 2000 characters)
- Configure GHL AI voice settings: response delay, interruption sensitivity, temperature, max tokens, silence timeout, end-call-on-silence
- Create test call scenarios with scoring rubrics and pass/fail criteria
- Build troubleshooting decision trees for common failures
- Write the definitive HVAC receptionist prompt handling: greetings, urgency assessment (emergency vs routine), info collection (name, address, phone, issue description, system type), appointment language, common Q&A, restrictions (no diagnosing, no quoting exact prices), call conclusion
- Create prompt variants for different HVAC types (residential, commercial, 24/7 emergency, seasonal)
- Build micro-prompt libraries for specific situations (angry caller, price shopper, emergency, wrong number, Spanish speaker, elderly caller)

**Voice-Specific Rules:**
- VOICE is not TEXT. Short sentences. No jargon. No lists. Conversational flow.
- 200ms of extra latency kills the illusion. Every word must earn its place.
- Always include confusion recovery: "I want to make sure I get this right — could you repeat that for me?"
- Always include emergency detection: gas leak, carbon monoxide, flooding, fire → "This sounds like an emergency. Please call 911 first, and we'll send someone as soon as it's safe."
- The greeting sets the entire tone — if the first 3 seconds feel robotic, the caller hangs up
- Build prompts that RECOVER from confusion instead of breaking down
- Include escape hatches — if the AI gets stuck, it always has a natural redirect
