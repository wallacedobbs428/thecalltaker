# Creatify Brief — `m1-price-97-01`

## Purpose

Control creative for the `START_FREE_PILOT` ladder.

This ad exists to destroy price resistance and move cold traffic into the low-friction signup path.

## Variant ID

- `m1-price-97-01`

## Goal

- primary: pilot signup intent
- secondary: lower price objection before the landing page

## CTA

- `SIGN_UP`

## CTA Destination

- `https://thecalltaker.com/start.html?plan=after-hours`

## UTM Content

- `m1_price_97_01`

## Source Script

- `ads/scripts/script-05-what-97-buys.md`

## Format

- 9:16 vertical
- 20-30 seconds
- fast-cut comparison style
- captioned

## Core Hook

- `What does $97 buy?`

## Required Story Beats

1. rapid underwhelming comparisons
2. hard pivot with `OR`
3. `730 hours` value reveal
4. one-missed-call math
5. direct free-pilot ask

## Required On-Screen Elements

- `$97`
- `730 HOURS`
- `START FREE PILOT`
- `14 days free`

## Visual Rules

- dark background
- green for gain
- red only for pain contrast
- no clutter
- no more than one big idea per shot

## Caption Rules

- burned-in captions
- emphasize:
  - `$97`
  - `730 hours`
  - `one missed call`
  - `start free`

## Thumbnail Brief

- text: `WHAT $97 BUYS`
- big green `$97`
- subline: `730 HOURS`

## Landing Rule

This ad must always land on:
- `start.html?plan=after-hours`

No detours to homepage.
No generic booking path.

## Kill Rule

If this ad gets attention but weak signup intent, the hook is fine and the offer framing is wrong.
Do not kill it before checking landing-path quality.

## Success Condition

This becomes the signup-ladder control if it consistently produces the strongest low-ticket pilot intent.
