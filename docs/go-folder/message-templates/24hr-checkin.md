# 24-Hour Check-in — Day After Going Live

## Metadata

| Field     | Value                                    |
|-----------|------------------------------------------|
| Subject   | n/a (SMS)                                |
| Channel   | SMS                                      |
| Trigger   | 24 hours after "live" tag applied        |
| Max Length | 2 segments (~300 characters)            |

## Template

```
Hey [FIRST NAME]! It's been about 24 hours since [BUSINESS NAME] went live — how's it going so far? Notice any calls coming through?

If you want us to tweak anything — the greeting, how it says your business name, the speed — just let us know. We're here to dial it in for you. 👊
```

## Usage Notes

- This is a high-value touchpoint. The first 24 hours determine whether a client feels confident or anxious about the service.
- Keep it casual and personal — this should read like a text from a friend, not a support ticket.
- legacy CRM automation: schedule to send exactly 24 hours after `live` tag is applied.
- Common adjustments clients request after day 1:
  - Change the greeting wording
  - Adjust name pronunciation
  - Speed up or slow down the voice
  - Add or remove services from the script
  - Change notification preferences
- If the client responds with an issue, escalate immediately. First-day problems kill retention.
- If the client responds positively, reply with enthusiasm and remind them about the referral program casually.
- Character count: ~268 characters (fits in 2 SMS segments).
