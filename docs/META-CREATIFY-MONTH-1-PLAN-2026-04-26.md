## Strategic Position

The account should run on two ladders:

1. `CALL_NOW` ladder
   Use the demo line as the conversion mechanism.
   This is the shortest path to intent and still the sharpest differentiator.

2. `START_FREE_PILOT` ladder

### Week 2 — Double Down on the Winners

Take the top 2 from week 1 and make 2 variants each:
- same hook, different opening scene
- same offer, different CTA framing
- same CTA, vertical-specific cut

### Week 3 — Verticalize the Winners

Only after a hook proves itself:
- HVAC version
- Plumbing version
- Locksmith version
- Dental / medspa / chiropractic if medical push is active

Do not invent new generic hooks in week 3.
Port the winner into vertical variants.

### Week 4 — Systematize

By week 4 you should know:
- best cold CTA
- best landing page
- best first-3-seconds hook
- best founder vs UI vs scenario format

Then:
- pause losers
- keep one control
- rotate only new challengers against the control

## Creatify Production Model

Creatify should not be used to create random novelty.
It should be used to manufacture disciplined variants fast.

### Use Creatify For

- angle variants of already-proven hooks
- different founder delivery styles
- niche overlays and transcript swaps
- captioned 9:16 reels
- fast challenger production against a control

### Do Not Use Creatify For

- inventing a new positioning every day
- mixing multiple CTAs in one ad
- making “cool” videos with no hard offer
- replacing direct-response copy with generic AI-fluff

## Control vs Challenger System

The account needs one control per ladder.

### Control A — Call Ladder

- Hook: `Hear Gideon Live`
- CTA: `CALL_NOW`
- KPI: cost per call intent / confirmed call action

### Control B — Signup Ladder

- Hook: `What $97 Buys`
- CTA: `SIGN_UP`
- Landing: `start.html?plan=after-hours`
- KPI: cost per start / lead / qualified pilot

### Challenger Rules

- challenger changes one thing only:
  - hook
  - opening scene
  - CTA framing
  - visual treatment
- challenger gets 48 hours minimum unless it is obviously dead
- challenger dies if:
  - spend is meaningful and CTR is weak
  - hook retention is poor
  - call intent or lead quality is garbage

## KPI Stack

Judge by ladder.

### Call Ladder

- thumb-stop / hold rate
- CTR
- call intent rate
- cost per call action
- downstream demo / pilot conversion after call

### Signup Ladder

- CTR
- landing page continuation
- cost per lead
- cost per qualified pilot
- eventual customer acquisition cost
